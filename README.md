# Mesud Ali portfolio (HTML, CSS, JavaScript)

No build step and no dependencies. Open `index.html` in a browser, or serve the folder.

## Files
- `index.html`  content and structure
- `styles.css`  design and responsive rules
- `script.js`   menu, scroll effects, and your contact details (see CONFIG at the top)
- `images/`     your photo and project screenshots

## Your details
Open `script.js` and fill in `email`, `linkedin` and `upwork` in CONFIG. Empty ones stay hidden.

## Project screenshots
Save images with these exact names in `images/` and they replace the grey boxes automatically:
- `askly.png`
- `habesha-coffee.png`
- `agro-board.png`
(about 1200 x 660 px works well)

## Real Askly chat widget (optional)
At the bottom of `index.html` there is a commented-out script tag. Add your demo data-key,
add this site's domain to that business's allowed websites in the Askly dashboard, then remove the comment markers.

## Deploy
Push to GitHub, then import the repo in Vercel (Framework: Other, no build command) or turn on GitHub Pages.
